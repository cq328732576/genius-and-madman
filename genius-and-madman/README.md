# Genius and Madman - 天才在左，疯子在右

**Phase 1: 锚点 vs 爆发 (Anchor vs Burst)**

双人本地合作 2D 平台跳跃游戏原型，实现天才的磁力锚点枪与疯子的爆炸冲刺机制。

## 快速开始

### 安装依赖

```bash
npm install
```

### 运行开发服务器

```bash
npm run dev
```

游戏将在 `http://localhost:3000` 启动。

### 运行测试

```bash
# 运行单元测试
npm test

# 运行 e2e 测试并生成截图
npm run e2e:shots
```

测试截图和录像将保存在 `artifacts/` 目录。

## 操作控制

### 天才（蓝色角色）

- **移动**: `W` `A` `S` `D` 键
- **放置锚点**: 鼠标左键点击（瞄准并放置）
- **瞄准**: 鼠标移动

### 疯子（橙色角色）

- **移动**: 方向键 `←` `→`
- **跳跃**: 方向键 `↑`
- **冲刺/吸附**: `Shift` + 方向键
- **瞄准窗口**: 吸附后按住 `Shift` 延长瞄准时间
- **消耗锚点**: 吸附时按住 `Ctrl`（增强弹射力，销毁锚点）

## 游戏机制

### 锚点系统（天才）

1. **放置限制**：
   - 最多同时存在 2 个锚点
   - 必须放置在可附着表面（绿色平台、地面、墙壁）
   - 不能放置在空中或不可附着表面（红色平台）
   - 射程限制：14 单位（约 448 像素）

2. **FIFO 替换**：
   - 放置第 3 个锚点时，自动移除最旧的锚点
   - **例外**：被疯子吸附/占用的锚点不能被移除
   - 如果所有锚点都被占用，放置失败并显示"锚点正在被使用"提示

3. **锚点状态**：
   - **就绪**（蓝色光圈）：可被吸附
   - **可吸附**（加亮光圈）：疯子冲刺路径将进入半径
   - **被占用**（虚线光圈）：疯子正在吸附，不可替换

### 冲刺与吸附（疯子）

1. **自动吸附**：
   - 冲刺路径进入锚点吸附半径（2.0 单位，约 64 像素）时自动吸附
   - 疯子被拉到锚点外侧 0.6 单位的悬停点
   - 进入瞄准窗口（默认 0.28 秒，按住 Shift 延长至 0.50 秒）

2. **短冲刺**：
   - 无锚点或路径未进入吸附半径时，执行短距离冲刺（4.0 单位）
   - 显示"未吸附"提示

3. **爆炸弹射**：
   - 瞄准窗口内可调整弹射方向
   - 弹射方向 = (1 - 0.6) × 接近方向 + 0.6 × 输入方向
   - 方向限制在 ±70° 锥角内
   - 基准初速：16 单位/秒
   - **保留锚点**：倍率 1.00
   - **消耗锚点**：倍率 1.35（更强弹射，销毁锚点）

4. **被打断保护**：
   - 吸附中锚点被移除时，疯子获得 0.15 秒短无敌
   - 仍会坠落，但不会受伤

## 调参配置

所有游戏参数在 `src/config/tuning.ts` 中可配置：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| **世界尺度** | | |
| 像素/单位 | 32 px | 1 单位 = 32 像素 ≈ 1 米 |
| 角色身高 | 1.8 单位 | 约 58 像素 |
| **天才：锚点枪** | | |
| 最大锚点数 | 2 | 同时存在上限 |
| 最大射程 | 14 单位 | 约 448 像素 |
| 放置冷却 | 0.35 秒 | 两次放置间隔 |
| **疯子：冲刺** | | |
| 短冲距离 | 4.0 单位 | 无吸附时的冲刺距离 |
| 冲刺冷却 | 0.60 秒 | 两次冲刺间隔 |
| 吸附半径 | 2.0 单位 | 自动吸附判定范围 |
| 悬停距离 | 0.6 单位 | 吸附后的悬停外偿 |
| 瞄准窗口 | 0.28 秒 | 基础瞄准时间 |
| 瞄准窗口（延长） | 0.50 秒 | 按住 Shift 可延长至 |
| 弹射初速 | 16 单位/秒 | 基准弹射速度 |
| 保留倍率 | 1.00 | 保留锚点的弹射倍率 |
| 消耗倍率 | 1.35 | 消耗锚点的弹射倍率 |
| 方向混合权重 | 0.60 | 输入方向权重（接近方向 0.40） |
| 方向锥角 | ±70° | 弹射方向限制范围 |
| 被打断无敌 | 0.15 秒 | 吸附被打断时的短无敌 |

✅ **条件 3**：冲刺路径进入吸附半径时自动吸附，悬停在外侧 0.6 单位  
✅ **条件 4**：路径未进入半径时执行短冲刺，显示"未吸附"提示  
✅ **条件 5**：所有参数通过 `tuning.ts` 可配置  
✅ **被打断规则**：吸附中锚点被移除时，疯子获得 0.15 秒短无敌

## 开发说明

### 调试模式

游戏内置调试面板（左上角），显示：
- 当前锚点数量
- 冲刺冷却时间
- 吸附状态
- 瞄准窗口计时
- 操作提示
- 实时调参值

通过 `src/config/tuning.ts` 中的 `debug.enabled` 开关控制。

### 修改调参

编辑 `src/config/tuning.ts` 中的 `defaultTuning` 对象即可。运行时调参（通过调试面板）功能待实现。
