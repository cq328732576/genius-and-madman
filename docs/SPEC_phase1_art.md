# 《锚点 vs 爆发》Phase1 临时表现素材规格

美术：Art Director ｜ 依据：设计文档「视觉与反馈清单」｜ 性质：占位素材，非成品，无付费/第三方素材。
目录：`sprites/`（PNG）、`previews/`（预览）、`_src/`（生成脚本，可重跑）。

## 0. 通用约定

- 格式：PNG-32，透明底，**非预乘 alpha**（straight alpha）。每个文件有 `@2x`（两倍像素）版本，同名加 `@2x`。
- 尺寸均为 2 的幂（射线 128×32 的宽高、徽标 256×64 均为 2 的幂）。
- 后缀：`_g` = 天才视角画面用（冷色、硬边几何）；`_m` = 疯子视角画面用（暖色、抖动/锯齿/尖刺）。
- **光圈本体恒用冷色（`anchor_halo_*_g`）**，因锚点属于天才；疯子画面里的吸附环 / 徽标 / 屏边箭头用 `_m`，与冷色光圈形成冷暖对比。`anchor_halo_*_m` 为备用（如将来需疯子占据标记），第一阶段默认不接。
- 素材已内置 1~2px 深色描边（#070B16）与轻微外发光，浅色背景上也能读。程序不需再加描边。
- 世界比例假设：1 单位 = 48px（1080p 单屏）。分屏每半屏 960×1080，沿用同一比例。若程序实际 PPU 不同，按“单位直径/半径”换算缩放，不按像素。
- 色值：
  | | 主色 ok | 副色 ok2 | 高光 light | 暗字/描边 dark | 禁止/未就绪 bad | 禁止叉 bad_x |
  |---|---|---|---|---|---|---|
  | 天才 g | #2FD5FF | #1F6BFF | #E6FBFF | #06142B | #8FA3BF | #FF4D6D |
  | 疯子 m | #FF8A1F | #FF3B2F | #FFE2B0 | #2B0A04 | #B5764E | #FFF0D0 |

## 1. 状态怎么不靠色相读出（验收项）

| 状态对 | 形状 / 字样差异（灰度版仍成立） |
|---|---|
| 射线 有效 / 禁止 | 实线 + 每 128px 一个「>」 ↔ 断裂虚线 + 缺口处「/」，线更细、无箭头 |
| 准星 有效 / 禁止 | 四角方括号 + 菱形 + 十字刻度（外形方） ↔ 虚线圆 + 粗 X（外形圆+叉） |
| 光圈 就绪 / 可吸附 / 占用 | 双层六边形+顶点方块 ↔ 外环加粗+半透明填充+6 个外刺 ↔ 全虚线、空心、中心一横 |
| 吸附环 常态 / 将进入 | 细单线圆+刻度 ↔ 粗环+内细环+4 个向心三角（+「可吸附」徽标） |
| 徽标 可吸附 / 未吸附 / 被占用 | 实心切角胶囊+▶◀ ↔ 空心虚线胶囊+X ↔ 空心双线胶囊+挂锁；三者都带文字 |
| 屏边箭头 就绪 / 未就绪 | 实心箭头+锚点符号+箭尖「✓」 ↔ 空心虚线箭头+虚线符号+箭尖「—」 |
| 疯子 vs 天才 | 同一形状语法，疯子为抖动/锯齿/尖刺外轮廓；不依赖色相 |

灰度验证见 `previews/*_gray.png`。

每项后缀 `_g` / `_m` 各一份，下表只写 `_g`；`@2x` 尺寸为 2 倍。

### b. 锚点光圈与落定脉冲

| 文件 | 尺寸 | Pivot | 说明 / 缩放 |
|---|---|---|---|
| `anchor_halo_ready_g.png` | 256×256 | 中心 | 闲置就绪：双层六边形+顶点方块+中心锚点符号。缩放 0.5（外径约 2.2 单位≈108px）。 |
| `anchor_halo_snap_g.png` | 256×256 | 中心 | 可吸附：外环加粗、半透明填充、6 外刺（“光圈加亮”）。进入吸附半径或冲刺将入半径时切换。 |
| `anchor_halo_locked_g.png` | 256×256 | 中心 | 占用/被锁定/不可吸附：全虚线空心。 |
| `anchor_pulse_g.png` | 1024×256（4 帧横排，每帧 256×256） | 每帧中心 | **落定脉冲**（叠加层，盖在 ready 光圈上方，同缩放 0.5，建议 Additive 或 Normal 均可）。 |
| `pulse_frames/anchor_pulse_g_00..03.png` | 256×256 | 中心 | 同上，单帧版。 |

脉冲时序（4 帧，不循环，共 250ms，约 16fps 但帧时长不等）：

| 帧 | 时长 | 内容 | 
|---|---|---|
| 00 | 0–50ms | 高亮实心小六边形 + 外环（落点爆闪） |
| 01 | 50–110ms（60ms） | 半径约 84 的粗白环 + 淡填充 |
| 02 | 110–180ms（70ms） | 半径约 104、80% 不透明 |
| 03 | 180–250ms（70ms） | 半径约 118 细环、45% 不透明；结束后移除，剩 ready 光圈 |

「保留后收一下」不另做图：程序对 ready 光圈做缩放 1.0→0.88→1.0（0.20s，ease-out），可叠加 Pulse 帧 03 淡出。脆弱锚（裂纹）与碎裂本阶段未做。

### d. 屏幕边箭头

| 文件 | 尺寸 | Pivot | 说明 / 缩放 |
|---|---|---|---|
| `edge_arrow_ready_g.png` | 128×128 | 中心；**箭头指向 +x** | 就绪：实心箭头，内嵌锚点符号（六边形+中心点），箭尖带 ✓。缩放 0.75（约 96px）。 |
| `edge_arrow_notready_g.png` | 128×128 | 中心 | 未就绪（被占用/被替换中）：空心虚线箭头，箭尖带 —。 |
| `edge_state_ready_g.png` | 64×64 | 中心 | **不随箭头旋转**的状态角标（实心六边形 ✓），叠在箭头上，选用。 |
| `edge_state_wait_g.png` | 64×64 | 中心 | 同上，未就绪（虚线空心 —）。 |

摆放建议：从屏幕中心指向锚点的连线与屏幕矩形（内缩 70px）的交点放置，旋转 = 指向角。内嵌锚点符号和 ✓ 会随箭头旋转；倒转时仍可读（符号接近旋转对称），若要正向 ✓，用 `edge_state_*`。同屏最多 2 锚点，故最多 2 个箭头。

## 3. 状态映射（设计文档「视觉与反馈清单」）

| 设计状态 | 使用素材 |
|---|---|
| 瞄准放置中·有效 | `aim_ray_valid_g` + `aim_reticle_valid_g` + `aim_range_arc_g`；疯子画面淡显 `aim_reticle_valid_g` alpha 0.4 |
| 放置失败 / 无效落点 | `aim_ray_forbidden_g` + `aim_reticle_forbidden_g`；被锁定：加 `snap_badge_inuse_zh_g` |
| 锚点闲置就绪 | `anchor_halo_ready_g`；落定时播 `anchor_pulse_g` 一次；画面外 → `edge_arrow_ready_*` |
| 可吸附 | `anchor_halo_snap_g` + `snap_ring_thin_m`(常态) ；路径将入半径 → `snap_ring_inrange_m` + `snap_badge_snap_zh_m` |
| 保留后 | 程序缩放 ready 光圈（见上） |
| 未吸附 | `snap_badge_miss_zh_m` |
| 锚点被占用/锁定 | `anchor_halo_locked_g`；画面外 → `edge_arrow_notready_*` |

天才画面的吸附环/箭头用 `_g`，疯子画面用 `_m`。

## 5. 已知限制与待定

- 细吸附环在缩小 50% 后线宽约 1.5px，仍可读但偏弱；如实机嫌弱，把 `snap_ring_thin` 缩放系数上调或让程序在低分辨率切换加粗线。
- 疯子版射线抖动幅度较小，已保证形状可读；动态效果（流动/抖动动画）需程序做 UV 滚动，未做帧动画。
- 设计文档写“射程弧”，本阶段只给弧段素材。慢速场、重力翻转、对拉连线、弹射轨迹/拖尾、脆弱裂纹不在本次范围（清单未列入 chief 任务 1-4）。
- 脉冲时长、保留收缩时长为美术建议值，需与程序/制作人确认。
- 重跑：`python3 _src/gen_sprites.py && python3 _src/gen_previews.py`。
